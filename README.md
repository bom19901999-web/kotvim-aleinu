# כותבים עלינו

אתר שאוסף כל 15 דקות כותרות על ישראל מכלי תקשורת בכל העולם, מתרגם אותן לעברית ומציג אותן עם קישור לכתבה המקורית.

## איך זה עובד

1. **`collect.py`** פונה ל־[GDELT](https://www.gdeltproject.org/) (חינם), מקבל כותרות אחרונות על ישראל ב־12 שפות, משאיר רק כותרות שבאמת עוסקות בישראל, מסיר כפילויות ומתרגם לעברית דרך Google Translate.
2. **`build.py`** בונה מהנתונים אתר סטטי: עמוד ראשי, עמוד לכל יום, ארכיון, אודות ו־sitemap לגוגל.
3. **GitHub Actions** מריץ את שני הסקריפטים כל 15 דקות ומעלה את האתר ל־**GitHub Pages**. הכול חינם, כל עוד המאגר ציבורי.

הגדרות (שם האתר, דומיין, מגבלות עלות) נמצאות כולן ב־**`config.py`**.

---

## העלאה לאוויר, צעד אחר צעד

### 1. חשבון GitHub ומאגר
1. נרשמים ב־https://github.com (חינם).
2. לוחצים **New repository**. שם, למשל: `kotvim-aleinu`. מסמנים **Public**. לוחצים **Create repository**.
3. בעמוד המאגר: **uploading an existing file**, וגוררים פנימה את כל הקבצים והתיקיות מהתיקייה הזו. לוחצים **Commit changes**.

> ⚠️ במק ובווינדוס התיקייה `.github` לפעמים מוסתרת ולא עולה בגרירה. אם אחרי ההעלאה אין במאגר תיקייה `.github`:
> **Add file → Create new file**, בשם הקובץ כותבים `.github/workflows/update.yml`, מדביקים את תוכן הקובץ `update.yml` ושומרים.

### 2. הפעלת GitHub Pages
**Settings → Pages**, ובשדה **Source** בוחרים **GitHub Actions**.

### 3. מפתח תרגום מגוגל
1. נכנסים ל־https://console.cloud.google.com ויוצרים פרויקט חדש.
2. בחיפוש למעלה: **Cloud Translation API**, ולוחצים **Enable**. גוגל תבקש לחבר כרטיס אשראי (חיוב רק מעבר ל־500 אלף תווים בחודש).
3. **APIs & Services → Credentials → Create credentials → API key**. מעתיקים את המפתח.
4. מומלץ: ליד המפתח, **Edit → API restrictions → Restrict key**, ובוחרים רק Cloud Translation API.
5. מומלץ מאוד: **Billing → Budgets & alerts**, ויוצרים התראה, למשל ב־30$ בחודש.

### 4. שמירת המפתח ב־GitHub
במאגר: **Settings → Secrets and variables → Actions → New repository secret**
- Name: `GOOGLE_TRANSLATE_KEY`
- Secret: המפתח מהשלב הקודם

### 5. הרצה ראשונה
לשונית **Actions**. אם מופיעה שאלה, מאשרים הפעלת workflows. בוחרים **עדכון כותרות**, ואז **Run workflow**.
אחרי 2–4 דקות האתר באוויר בכתובת:
`https://<שם-המשתמש>.github.io/<שם-המאגר>/`

מכאן הוא מתעדכן לבד כל 15 דקות.

### 6. דומיין משלך (כשרוצים)
1. קונים דומיין (למשל ב־Namecheap, Cloudflare או רשם ישראלי ל־‎.co.il).
2. ב־`config.py` ממלאים `CUSTOM_DOMAIN` (למשל `kotvim-aleinu.co.il`) ו־`SITE_URL` (למשל `https://kotvim-aleinu.co.il`).
3. אצל הרשם, ב־DNS, מוסיפים:
   - ארבע רשומות **A** לשורש הדומיין: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - רשומת **CNAME** עבור `www` שמצביעה על `<שם-המשתמש>.github.io`
4. ב־**Settings → Pages** מזינים את הדומיין ומסמנים **Enforce HTTPS** (אחרי שהאישור מוכן, לפעמים עד יום).

### 7. גוגל ופרסומות
- **Google Search Console**: מוסיפים את האתר ושולחים את `sitemap.xml`, כדי שגוגל יתחיל לאנדקס את עמודי הימים.
- **AdSense**: אחרי שיש תנועה ותוכן, מגישים בקשה. כשמאושרים, ממלאים את `ADSENSE_CLIENT` ב־`config.py`.

## שליטה בעלות
- `MAX_NEW_PER_RUN` ב־`config.py` מגביל כמה כותרות חדשות מתורגמות בכל ריצה. ברירת המחדל, 60, היא תקרה של כ־5,700 ביום. בפועל, אחרי הסינון, יהיו הרבה פחות.
- כל כותרת מתורגמת פעם אחת בלבד.
- ביומן של כל ריצה (לשונית Actions) כתוב כמה תווים נשלחו לתרגום.

## בדיקה מקומית (לא חובה)
```
python collect.py   # בלי מפתח: הכותרות נשמרות בשפת המקור
python build.py
# ואז פותחים את site/index.html בדפדפן
```
